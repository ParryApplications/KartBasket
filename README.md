## 🛒 About KartBasket

**KartBasket** is a premium e-commerce website that showcases curated products across multiple categories with direct Amazon links for seamless shopping experience. Built with modern web technologies and designed with a professional, premium aesthetic.

### ✨ Key Features

- **Premium Design**: Elegant and professional UI with gold accents and smooth animations
- **Fully Responsive**: 100% responsive design optimized for all devices:
  - 📱 Smartphones (all screen sizes)
  - 📱 Tablets
  - 💻 Laptops & Desktops
  - 📺 Large screens & TVs
- **Product Categories**: 
  - Electronics
  - Home & Kitchen
  - Fashion
  - Books
  - Sports & Fitness
  - Beauty & Personal Care
- **Direct Amazon Integration**: Each product links directly to Amazon for trusted purchasing
- **Featured Products**: Handpicked premium items highlighted on the homepage
- **Filter System**: Easy product filtering by category
- **Smooth Animations**: Professional transitions and scroll effects
- **SEO Optimized**: Meta tags and semantic HTML for better search engine visibility
- **Performance Optimized**: Lazy loading images and optimized code

## 🛠️ Installation & Setup

1. **Clone or Download** the project files
2. **Open** `index.html` in your web browser
3. **No build process required** - it's a static website!

### Local Development

Simply open the `index.html` file in any modern web browser:

```bash

cd KartBasket

# Open in default browser (macOS)
open index.html

# Or use a local server (recommended)

# Then visit http://localhost:8000
```

## 📝 Configuration

### Updating Site Information

Edit [`js/constants.js`](js/constants.js:1) to customize:

```javascript
const SITE_CONFIG = {
    SITE_NAME: 'KartBasket',
    DEVELOPER_NAME: 'ParryApplications',
    DEVELOPER_URL: 'https://parryapplications.com/',
    TAGLINE: 'Your Premium Shopping Destination',
    COPYRIGHT_YEAR: new Date().getFullYear()
};
```

### Adding Products

Add new products to the `PRODUCTS` array in [`js/constants.js`](js/constants.js:1):

```javascript
{
    id: 25,
    name: 'Product Name',
    category: CATEGORIES.ELECTRONICS,
    price: '₹2,999',
    originalPrice: '₹5,999',
    discount: '50% OFF',
    rating: 4.5,
    reviews: 1250,
    image: 'https://example.com/image.jpg',
    description: 'Product description',
    amazonLink: AMAZON_LINKS.YOUR_PRODUCT,
    featured: false
}
```

### Updating Amazon Links

Modify the `AMAZON_LINKS` object in [`js/constants.js`](js/constants.js:1):

```javascript
const AMAZON_LINKS = {
    YOUR_PRODUCT: 'https://www.amazon.in/dp/PRODUCT_ID'
};
```
